## 3. 备份维度 4 分类（强制）

每个子平台必须按 4 类梳理自己的资产：

### A · 业务数据（数据库）

| 数据库类型 | 备份方法 | 备注 |
|---|---|---|
| **PostgreSQL** | `pg_dump` → `<product_code>_pg.sql.gz` | 需嵌入 PG 自带 pg_dump 或系统 PATH |
| **SQLite** | `cp <db>.db` 文件（先停 daemon） | 单文件，< 100MB |
| **H2 file** | `cp <db>.mv.db` 文件（先停 daemon） | H2 包含 .mv.db + .trace.db |
| **H2 in-memory** | ❌ 不支持（dev 用） | 上线前必须改 file 模式 |

### B · 应用密钥（必备份）

- JWT secret / SSO secret（**密钥丢 = 全部 token 失效**）
- 第三方 API key（飞书/钉钉/支付等）
- 数据库密码配置
- HTTPS 证书 / 私钥
- 各平台 `.env` / `application*.yml` 中的敏感字段

**所有密钥必须单独加密备份**，不能与代码混在一起。

### C · 构建产物

- Java: `target/*.jar`
- Python: `dist/*.whl` 或 `build/`
- Vue/前端: `dist/` 或 `build/`
- Docker: `docker save` 镜像 tar
- 其他: 任何编译/打包产物

### D · 源代码（分层策略）

| 子平台状态 | 代码备份策略 |
|---|---|
| **有 git 远程仓库** | 主：Git 远程（强制）；兜底：NAS 月度冷备 |
| **无 git 仓库**（AIDD/MED-PPT）| NAS 必备份 + 强烈建议先初始化 git |

## 6. 互不冲突机制（8 条铁律）

### 6.1 目录隔离

**规则**：每个子平台独立 `CODE/<product_code>/` 目录，目录间互不影响。

```bash
# AIDD 写：/Volumes/176XXXX8727/CODE/aidd/backup/...
# MPDM 写：/Volumes/176XXXX8727/CODE/mpdm/backup/...
# 互不干扰：rsync 不同目录是文件系统独立操作
```

### 6.2 文件名前缀

**规则**：所有备份文件以 `<product_code>_` 开头。

```bash
# 正确
/Volumes/176XXXX8727/CODE/geom/backup/2026-XX-XX/geom_sqlite.db
/Volumes/176XXXX8727/CODE/dinfo/backup/2026-XX-XX/dinfo_h2.mv.db

# 错误（多个子平台公用会冲突）
/Volumes/176XXXX8727/CODE/geom/backup/2026-XX-XX/db.db
```

### 6.3 时间戳命名

**规则**：每次备份独立时间戳目录（`YYYY-MM-DD_HH-MM-SS/`）。

```bash
# 同一天多次备份自动独立目录
2026-09-08_20-21-21/
2026-09-08_20-24-51/
2026-09-08_20-26-57/

# 避免冲突 + 保留历史
```

### 6.4 软链局部化

**规则**：每个子平台目录有自己的 `latest` 软链（在各自目录内）。

```bash
# AIDD 自己的 latest
/Volumes/176XXXX8727/CODE/aidd/backup/latest -> 2026-09-08_20-30-00

# MPDM 自己的 latest
/Volumes/176XXXX8727/CODE/mpdm/backup/latest -> 2026-09-08_22-00-00

# 互不影响
```

### 6.5 并发安全

**规则**：rsync 是文件级操作，不同目录并发写安全。

```bash
# AIDD 和 MPDM 同时跑备份，互不阻塞
bash /Users/hua/Documents/myself/AIDD/scripts/backup_to_nas.sh &
bash /Users/hua/Documents/myself/MPD-myself/scripts/backup_to_nas.sh &
wait
```

⚠️ **不允许多个脚本同时写同一个目录**（会产生时间戳目录冲突的极小概率，但应避免）。

### 6.6 删除隔离

**规则**：删除自己目录不影响其他子平台。

```bash
# 删 AIDD 备份
rm -rf /Volumes/176XXXX8727/CODE/aidd/backup/2026-08-*

# MPDM / GEOM 等完全无影响
```

### 6.7 容量配额监控

**规则**：每个子平台单独统计容量，超过阈值告警。

```bash
# 主站窗口每月监控
du -sh /Volumes/176XXXX8727/CODE/*/backup/

# 示例输出：
# 12M  /Volumes/176XXXX8727/CODE/lingyao/backup/
# 8M   /Volumes/176XXXX8727/CODE/geom/backup/
# 4M   /Volumes/176XXXX8727/CODE/mpdm/backup/
# ... 各子平台单独统计
```

阈值建议：
- 单子平台 L2 全量 < 200MB
- 30 天保留 × 200MB = 6GB / 子平台
- 7 个子平台总计 < 50GB（NAS 数据盘 33T+，**完全够用**）

### 6.8 调度错峰

**规则**：手动触发天然错峰，避免同时跑。

- 当前是手动触发（V2.0.77.8 拍板），不设 cron
- 即使将来设 cron，错开启动时间（每个子平台 backup 在不同分钟启动）
