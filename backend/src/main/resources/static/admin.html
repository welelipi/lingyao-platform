📄 合同模板规格

三档合同模板（BASIC / PRO / FLAGSHIP）与 GEOM 套餐档位一一对应。新建/编辑公司表单内有「合同模板」下拉 + 「📄 预览合同」按钮 —— 选定档位后可直接预览合同正文（含签约方信息、套餐规格、定价、有效期）。

条款对齐口径：合同模板档（contractTemplate）与 GEOM 套餐档（geomPlan）可独立设置 —— 商务合同档可能滞后于实际授权（如先签 PRO 试用 1 个月，实际授权仍是 BASIC）。两者通过「公司表单」分别维护，修改任意一项都会写入审计日志。

销售系统同步：本期仅主站后台维护合同档与年费；后续销售系统对接由销售侧接管（不在本窗口）。V2.0.77.14 本版本仅落地「主站侧商业配置 Tab + 三档展示 + 公司表单字段」。
